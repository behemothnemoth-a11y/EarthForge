# 621 Main — Micro Depth v003

## Goal

Make the approved ornate storefront concept read correctly from:

- straight-on elevation;
- player-eye sidewalk view;
- 3/4 street view;
- upward close view.

## Main changes from v002

### Storefront

v002:
- frame and lattice existed, but lived too close to one facade plane.

v003:
- outer green frame projects toward the street;
- display opening has a deep brick/green reveal;
- lattice is set behind the outer frame;
- door is set even deeper;
- transom lives on its own intermediate plane;
- sign fascia projects independently above it.

### Upper windows

Each upper opening now has:

- deep brick reveal;
- recessed black lattice plane;
- pale projecting surround;
- projecting sill;
- projecting header;
- open void behind the lattice.

### Cornice

The cornice is rebuilt as a real section:

1. lower pale support band;
2. intermediate brick shadow band;
3. deeper pale shelf;
4. bracket groups;
5. upper cap before parapet.

### Parapet

The parapet gains:

- setback from the cornice;
- corner emphasis;
- stepped center;
- cap thickness;
- limited medallion accents.

### Roof

The roof skin starts behind the parapet rather than reading flush with the
front facade.

## Still excluded

- glass;
- room partitions;
- furniture;
- text signage;
- custom textures.
