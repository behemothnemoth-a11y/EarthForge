# Lombard retaining / planter edge finish v022

v022 is a material-only public-realm detail pass on the accepted v021 artifact. Buildings, road geometry, sidewalks, stairs, railings, planting geometry, registration and all occupancy are frozen.

The first draft was intentionally rejected as too broad: it would have recolored roughly 351k wall cells. The promoted pass touches only the visible coping/top band and at most the top three microcells of existing source-bounded retaining/planter columns.

The edit changes 17,418 microcells across 7,194 existing columns. No cell changes occupancy. Concrete tones are sampled from the cached CC0 Lombard Street Cherry Blossom reference and used only as a restrained color family; the photograph is not treated as calibrated albedo. The hairpin reference is used to judge curved-edge character.

Protection is parent-relative: v021 already contains accepted endpoint road repairs on coordinates that originated in v009. v022 therefore preserves the exact v021 value at every occupied v009 road/curb coordinate, including intentional air created by the v021 cap repair. No protected coordinate is written by v022.

Required gates: exact Litematica readback, exact Astra readback, material-only edits, declared retaining-edge scope only, v021 parent values preserved at all accepted v009 coordinates, and all vanilla/registration blocks preserved.

Load at the established Lombard placement, rotation 0, mirror none, replace ALL including air. Stop for flyaround review before further detailing.
