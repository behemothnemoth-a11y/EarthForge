# West Main Reference Rebuild v003

This pass intentionally wipes the entire current 617–627 facade strip and
rebuilds all five street fronts from the approved historic storefront concept.

## Facades

South → north:
- 617–619 — low brown one-storey storefront
- 621 — ornate green three-window historic facade
- 623 — large five-window central green facade
- 625 — compact blue/teal three-window facade
- 627 — burgundy/red three-window facade with roundel crest

## Microblock geometry

Each facade is authored as a continuous microcell sculpture before host
splitting.

The facades use:
- 1.5–2.4 block-deep display/entry wells;
- recessed door planes;
- deep window reveals;
- projected stone surrounds;
- sloped awnings;
- diagonal supports;
- pediments;
- stepped parapets;
- connected finials / roundels / brackets.

No glass is generated.
