# 1040 Lombard conservative source shell v031

v031 is the first Minecraft building geometry after the 1040 source reset. It is deliberately much simpler than rejected v025/v026.

## Authorized claims

Only three controls are allowed into this schematic:

1. the DataSF source footprint for building `201006.0032105`;
2. the accepted v024 driveway datum immediately outside the 1040 frontage;
3. the existing source absolute vertical envelope derived from the tracked median first-return control.

The street-facing footprint edge remains derived spatially from the source footprint and accepted crooked-road alignment.

## Geometry

The candidate is a hollow neutral perimeter shell. It has no interpreted roof, floor slab, facade openings, bays, terrace, pergola, or styling.

Wall bases use the accepted driveway datum as a lower review control. Where nearby accepted exterior support is higher, the visible wall starts at that support so the review shell does not intentionally render buried wall faces. This base stepping is a visibility treatment only; it is not a foundation or finished-floor measurement.

The top is only an envelope ring at the source vertical control. It is explicitly not a roof plane.
