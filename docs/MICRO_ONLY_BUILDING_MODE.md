# EarthForge Micro-Only Building Mode

Micro-Only mode exists for real buildings whose facade proportions are too
fine for 1-meter vanilla blocks.

The rule is intentionally strict:

- surrounding roads / sidewalks may remain vanilla;
- the target building above ground is built entirely from Astra Microblock hosts;
- no vanilla glass is allowed;
- window openings remain physically open;
- trim, lattice and mullions are microblocks;
- roofs and floors are microblock skins rather than full vanilla slabs;
- interiors are not generated yet.

## Why this mode exists

At roughly 1 block = 1 meter, many real storefronts are only 6–8 blocks wide.
Vanilla full blocks force windows, piers, cornices and doors into proportions
that are visibly wrong.

Astra's 16×16×16 host grid gives EarthForge a 1/16-block precision layer while
preserving the real-world footprint.

## 621 test

The first Micro-Only target is the same 621 Main / Carpets Plus footprint used
by the previous Truth Lab, but the visual target is the ornate historic
storefront concept approved in chat:

- red-brick upper facade;
- pale stone trim;
- dark-green storefront;
- three tall upper window openings;
- two broad lower storefront openings;
- centered paired door;
- layered historic cornice;
- stepped parapet;
- corner ornaments;
- no glass.

This is intentionally a visual-quality prototype rather than a claim that every
ornament exactly matches 621's current real facade.
