# 621 Main — Micro-Only Prototype v002

## Target

Rebuild 621 from scratch using Astra hosts for the complete building envelope.

### Facade
- 8-block frontage from the real footprint;
- dark-green lower storefront frame;
- open left/right storefront window voids;
- centered paired microblock door;
- cream trim/lattice;
- 3 tall upper window openings;
- red-brick upper wall;
- layered cream cornice;
- stepped brick parapet;
- small corner medallions.

### Glass
**None.**

Window areas are intentionally open until transparent Astra materials exist.

### Building envelope
- thin microblock wall skins on all exterior faces;
- microblock ground-floor floor skin;
- microblock second-floor plate;
- microblock roof skin;
- rear service door and two framed openings;
- no room partitions.

## Patch behavior

This is still a 621-only patch using the normal EarthForge global origin.

Paste with:
- same yellow registration point;
- rotation 0;
- mirror none;
- Replace Blocks: ALL.

The patch region includes air, so the previous 621 version is wiped first.
