# Lombard Endpoint Roads v015

This pass keeps v014b and adds only the top Hyde and bottom Leavenworth roadway surfaces needed to establish real endpoint/intersection control. Each cross street uses the DataSF centerline, a 50m review segment centered on Lombard, pavement width derived from DataSF ROW minus recorded sidewalk widths, and a smoothed LiDAR centerline profile. The existing v009 Lombard road/curb is immutable where the surfaces meet. Hyde cable-car rails, endpoint curbs, sidewalks, parking/markings, and buildings remain excluded.
