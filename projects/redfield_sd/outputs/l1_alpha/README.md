# Redfield POC 001 L1 Alpha

`Redfield_POC_001_L1_Alpha_v003.litematic` is the first architecture-forward,
normal-block-only reconstruction.

It includes inferred address matching, hollow building shells, storefront
glazing/sign bands, varied parapets, landmark treatment, and revised streets.

It is still an alpha: exact facade colors, openings, and story heights require
current-photo / Street View verification.
