# Redfield POC 001 L1 Visual

`Redfield_POC_001_L1_Visual_v004.litematic` is the first exterior-fidelity
normal-block reconstruction.

It adds property-bearing blocks, building-specific facade profiles, awnings,
doors, cornices, streetlights, planters, benches, parking markings, and a more
distinct north-end/City Hall treatment.

It is still intentionally pre-Microblocks.
