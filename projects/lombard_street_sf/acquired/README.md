# Acquired Lombard source snapshot

This directory is generated by `pipeline/acquire/lombard_datasf.py`.

Committed source snapshot:

- `centerline_wgs84.geojson` — assembled Hyde → Montclair Terrace → Leavenworth centerline.
- `centerline_segments_wgs84.geojson` — original DPW CNN source segments.
- `contours_wgs84.geojson` — local DataSF contour features intersecting the expanded corridor box.
- `acquisition.json` — exact queries, selected CNNs, bounds, timestamp, and counts.

Current DPW source path:

- CNN `8449000`: Hyde ↔ Montclair Terrace
- CNN `8448000`: Montclair Terrace ↔ Leavenworth

The two source segments share the Montclair Terrace endpoint and are assembled
into one Hyde-to-Leavenworth route before EarthForge generation.

The DataSF source data is public-domain licensed. The separate 2025 DWR LiDAR
profile is sampled through its ImageServer and stored as derived numeric road
samples rather than committing the full 1-foot raster.
