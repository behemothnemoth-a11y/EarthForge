# Lombard road truth

This directory contains project-local truth generated from recorded sources.

Current generated artifacts:

1. `locked_frame.json` — Hyde-anchored metric frame.
2. `centerline_local.json` — assembled 204.59 m Hyde → Leavenworth route.
3. `contours_local.geojson` — DataSF contour geometry transformed into the same local frame.
4. `elevation_candidates.json` — contour-crossing candidates in San Francisco Elevation Datum.
5. `lidar_profile_navd88.json` — primary dense road elevation profile from 2025 DWR LiDAR (generated by `sample_lidar_profile.py`).

## Vertical datum rule

The DataSF contours and DWR LiDAR use different vertical datums.

- DataSF contours: San Francisco Elevation Datum.
- DWR 2025 LiDAR: NAVD88.

They may be compared for shape/trend but must not be numerically merged without
an explicit vertical-datum transformation. NAVD88 LiDAR is the primary source
for the generated Lombard road grade.

## Build order

Do not place stairs, terraces, landscaping, lots, or buildings into the
authoritative pipeline before the road stages are accepted.
